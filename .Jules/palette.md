## 2024-07-07 - [Proper Label and Error Linking in Reusable Form Components]
**Learning:** When building custom form components (like `Input`, `Select`, and `Textarea`) in React, labels (`htmlFor`) and error messages (`aria-describedby`) are not inherently linked to the form control. Without explicitly setting these relationships, screen readers cannot associate the descriptive text or the error context with the input element.
**Action:** Use `React.useId()` within the component to generate a unique ID. Link the `<label>` using the `htmlFor` attribute. Link error messages using `aria-describedby` while supporting custom `aria-describedby` props, and add `aria-invalid` for visual/assistive context. Destructure custom ARIA attributes out of props so they don't overwrite the internally constructed values via spread (`{...props}`).
