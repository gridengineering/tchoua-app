## 2024-05-18 - [Form Component Accessibility: Link labels and errors using explicit IDs]
**Learning:** Custom UI components like `Input`, `Select`, and `Textarea` frequently encapsulate their own `<label>` and `<p>` error elements. Without generating explicit unique IDs (e.g. via `React.useId()`), linking them using `htmlFor` and `aria-describedby`, screen readers and assistive technologies cannot properly associate the label or error message with the correct form field. Moreover, we must extract and destructure out passed accessibility attributes like `aria-describedby` from `...props` to manually append our own `errorId` without it being overridden by the React spread.
**Action:** When building custom form components (like Input, Select, and Textarea), use `React.useId()` to generate a unique ID for the input element, link the associated `<label>` using the `htmlFor` attribute, and link error messages using `aria-describedby` for full accessibility and usability. Prevent the spread operation from inadvertently overwriting the internally constructed values.
