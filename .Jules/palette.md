## 2024-05-24 - [Forms A11y] Link Labels and Error Messages in Custom Components
**Learning:** Custom UI components like `Input`, `Select`, and `Textarea` often accept `label` and `error` text as props, rendering the `<label>` and error `<p>` alongside the actual HTML input element. If the `<label>` doesn't have an `htmlFor` matching the input's `id`, screen readers won't announce the label when the input is focused. If the error isn't linked via `aria-describedby`, screen reader users might not know why validation failed.
**Action:** Always use `React.useId()` in custom form components to generate unique IDs if none are provided. Link `<label>` with `htmlFor={id}`, link error messages with `aria-describedby={errorId}`, and add `aria-invalid={!!error}` for robust accessibility.
