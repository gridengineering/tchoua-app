## 2024-06-25 - Custom Form Components Need Explicit ARIA Linking
**Learning:** When abstracting standard HTML inputs (like `<input>`, `<select>`, `<textarea>`) into custom UI components (e.g., `Input`, `Select`, `Textarea`), accessibility is often broken because labels and error messages are visually adjacent but programmatically disconnected. This means screen readers won't announce the label when focusing the input, and won't read out error messages when an input is invalid.
**Action:** Always use `React.useId()` inside custom form components to generate a unique ID. Use this ID to explicitly link `<label htmlFor={id}>` to the `<input id={id}>`. For error messages, generate a related ID (e.g., `${id}-error`) and link it to the input using `aria-describedby`, while also toggling `aria-invalid={!!error}`.
