## 2024-05-19 - Clear Empty States for Dynamic Filters
**Learning:** In dynamically filtered interfaces like API Documentation pages, relying on the default 'empty space' behavior for un-matched queries confuses users. It is crucial to have a clear empty search state.
**Action:** Always include a visual, empty state indicator with a helpful message, a recognizable icon, and an explicit clear/reset action (like "Effacer la recherche") when building dynamic filtering lists or tables.
