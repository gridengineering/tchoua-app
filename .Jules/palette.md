## 2026-06-15 - Form Accessibility: Label & Error Associations
**Learning:** A critical pattern observed in the custom form components (Input, Select, Textarea) was the absence of explicitly linked IDs between form controls, their corresponding labels (`htmlFor`), and error messages (`aria-describedby`). Even with semantic HTML tags like `<label>`, screen readers may fail to associate the label text or error states with the input field without explicit ID-based relationships. Furthermore, indicating form errors to assistive technology requires not just visual cues but `aria-invalid={true}`.
**Action:** When creating or modifying custom form control components in React, always enforce the generation of unique IDs using `React.useId()` if no ID is provided, and use this generated ID to correctly link the `<label>` using `htmlFor`, and any error message containers using `aria-describedby`. Add `aria-invalid={true}` conditionally when an error is present.
