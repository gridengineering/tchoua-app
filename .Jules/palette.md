## 2024-06-25 - Accessibility of icon-only header elements
**Learning:** Across the application's top navigation bars (`header.tsx` and `public-layout.tsx`), many interactive elements like user menus, notification bells, and mobile toggles rely exclusively on icons (e.g., `<Menu />`, `<Bell />`) without accompanying text or explicit accessible names. This creates a barrier for screen reader users and those navigating via keyboard, who have no text to identify the purpose of the control.
**Action:** Always verify that every interactive element using an icon visually has a semantic textual equivalent for assistive technology. If the button is icon-only, it MUST have an `aria-label` attribute (for screen readers) and a `title` attribute (for visual tooltips on hover). Additionally, ensure that every button has visible focus states (e.g. `focus-visible:ring-2`) to assist keyboard-only navigation.
