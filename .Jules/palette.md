## 2026-06-19 - Global Header Accessibility Patterns
**Learning:** Found a recurring pattern in the app's global navigation (like `src/components/layout/header.tsx`) where icon-only buttons (`<Menu>`, `<MessageSquare>`, `<Bell>`, user menu) and `<Link>`s used for global actions lacked `aria-label`s and `title` attributes. Additionally, they were missing visual keyboard focus indicators, which is critical for non-mouse users navigating the main interface.
**Action:** Always verify that every icon-only button and link contains a descriptive `aria-label`, a `title` (for mouse hover tooltips), and explicit keyboard focus styles like `focus-visible:ring-2 focus-visible:ring-forest focus:outline-none`. For elements that toggle menus, ensure `aria-expanded` is also implemented correctly.
