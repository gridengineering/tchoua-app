## 2024-06-11 - Accessible Icon-Only Buttons in App Shell
**Learning:** The application shell (`header.tsx` and `sidebar.tsx`) heavily utilizes icon-only buttons for critical navigation (mobile menu, chat, notifications, user menu). These were missing proper ARIA labels and keyboard focus states, making the primary navigation experience poor for screen reader users and keyboard navigators. Native tooltips (`title`) combined with `aria-label` provide the best balance of visual guidance for mouse users and semantic meaning for assistive tech.
**Action:** Always verify that interactive elements in global layout components have `aria-label`, `title`, and explicit Tailwind focus states (`focus-visible:ring-2 focus-visible:ring-forest focus:outline-none`) applied, especially when they only contain Lucide icons.
