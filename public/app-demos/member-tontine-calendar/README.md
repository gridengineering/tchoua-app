# Tontine Calendar

Toutes vos prochaines sessions, au même endroit.

## Scope

`MEMBER` — Espace membre.

## Fonctionnalités

- Prochaines sessions
- Dates de tirage
- Rappels avant échéance
- Vue personnelle et association

## Lancer en local

Ouvrez `index.html` ou servez le dossier avec `python3 -m http.server`.

Le contexte Tchoua est récupéré depuis `/api/apps/sdk/context` avec le jeton `tchoua_token`.
