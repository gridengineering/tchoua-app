# Event Planner

Planifiez vos événements sans rien oublier.

## Scope

`ASSOCIATION` — application de démonstration du programme Tchoua Apps.

## Lancer en local

Ouvrez `index.html` ou servez ce dossier avec `python3 -m http.server`.

Le contexte Tchoua est récupéré depuis `/api/apps/sdk/context` avec le jeton `tchoua_token` fourni par la plateforme.
