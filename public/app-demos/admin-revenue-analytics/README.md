# Revenue Analytics

Vos revenus et tendances, sans angles morts.

## Scope

`ADMIN` — Administration.

## Fonctionnalités

- Revenus par source
- Croissance mensuelle
- Commissions et frais
- Comparaison des associations

## Lancer en local

Ouvrez `index.html` ou servez le dossier avec `python3 -m http.server`.

Le contexte Tchoua est récupéré depuis `/api/apps/sdk/context` avec le jeton `tchoua_token`.
