# User Health

Comprenez l'activité et la rétention des membres.

## Scope

`ADMIN` — Administration.

## Fonctionnalités

- Membres actifs et inactifs
- Rétention par cohorte
- Anomalies d'usage
- Segments à accompagner

## Lancer en local

Ouvrez `index.html` ou servez le dossier avec `python3 -m http.server`.

Le contexte Tchoua est récupéré depuis `/api/apps/sdk/context` avec le jeton `tchoua_token`.
