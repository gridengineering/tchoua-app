# Compliance Monitor

Gardez les dossiers KYC et les alertes sous contrôle.

## Scope

`ADMIN` — Administration.

## Fonctionnalités

- File de dossiers à revoir
- Score de risque par membre
- Alertes KYC et LBC-FT
- Export de la file de contrôle

## Lancer en local

Ouvrez `index.html` ou servez le dossier avec `python3 -m http.server`.

Le contexte Tchoua est récupéré depuis `/api/apps/sdk/context` avec le jeton `tchoua_token`.
