# Meeting Minutes

Préparez et archivez vos comptes rendus de réunion.

## Scope

`ASSOCIATION` — Espace association.

## Fonctionnalités

- Ordre du jour
- Points de décision
- Actions et responsables
- Archivage du compte rendu

## Lancer en local

Ouvrez `index.html` ou servez le dossier avec `python3 -m http.server`.

Le contexte Tchoua est récupéré depuis `/api/apps/sdk/context` avec le jeton `tchoua_token`.
